When working on this project, please consider this workflow to help us as a team
stay organised and ensure that no conflicts arise. Thank you.

-----------------------------------------------------------------------
1. Select/receive a ClickUp task.
2. Ensure the task has an owner and acceptance/definition of done.
3. Create the relevant GitHub Issue where appropriate.
4. Create a branch from main (if needed).
5. Make meaningful commits that add value.
6. Push branch.
7. Open Pull Request.
8. Link ClickUp task / requirement / GitHub Issue.
9. Both other team members review.
10. Resolve requested changes.
11. Receive two approvals.
12. Merge into main.
13. Update ClickUp task to Done.
14. Update RTM/PED/registers where affected.
------------------------------------------------------------------------
